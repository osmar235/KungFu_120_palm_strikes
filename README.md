# Palm strike EMG: task goal, repetition and timing consistency

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24518155.svg)](https://doi.org/10.5281/zenodo.24518155)

Data and analysis code for the manuscript *Task goal and repetition shape agonist and antagonist activity in a ballistic Kung Fu palm strike* (Pinto Neto, submitted to Human Movement Science).

## Data (`data/`)
Surface EMG from 9 Yau-Man Kung Fu practitioners (P1 to P9), recorded in December 2008 and January 2009 (Universidade do Vale do Paraíba, ethics protocol H226/2007/CEP). One file per participant and condition: `P<k>/<goal>_<n>.csv.gz`, where `goal` is `impact` (maximal force against a training shield) or `no_impact` (maximal speed in the air) and `n` is the series length (1, 10 or 120 alternating palm strikes). Columns: `t_s` (s), then the raw EMG of the instrumented arm in volts at the amplifier output: `DA` anterior deltoid, `TB` triceps brachii, `BR` brachioradialis, `DP` posterior deltoid. Sampling rate 1000 Hz; 4 channel system (EMG400C, EMGSystem, Brazil), total gain 2000. Participants are identified only by code; no key to names is included.

## Code (`code/`)
| Script | What it does |
|---|---|
| `pipeline_core.py`, `short_event_decisions.csv` | Shared methods and parameters: filtering, envelopes, ipsilateral strike detection (with the reviewed events of the 10 strike series), onset rule |
| `pipeline.py` | Main analyses (activation sequence, task goal, 120 strike bout) → `results.json` and CSV tables |
| `pipeline_sensitivity_v1_1.py` | Sensitivity: unnormalized post-reference ratio, reference-free timing, strike-level order |
| `pipeline_sensitivity_v1_2.py` | Sensitivity: onsets at the window edge, posterior deltoid without P5 |
| `pipeline_timing_v1_3.py` | Timing consistency across strikes and activation profile (rise time, peak-aligned ensembles) |
| `pipeline_timing_robust_v1_4.py` | Robust dispersion (MAD, IQR) of the timing-consistency measures |
| `audit_long_bouts.py`, `template_check.py`, `event_decisions.csv` | Review of the ipsilateral events of the 120 strike series: frozen visual decisions (32 exclusions, 6 insertions, 1 retained event), a check that each decision matches a detector and template discrepancy, and bout statistics for the original, reviewed, first-60 and first-56 event lists |
| `pipeline_rise_v1_3.py` | Rise descriptors of the activation profile (20 to 80% rise time, onset to peak) |
| `make_figures.py`, `make_figure5_v1_3.py` | Figures 1, 2, 3 and 5 (assert headline numbers before drawing); `fig4_bout.png` written here uses the automated event list, and the manuscript Figure 4 is the reviewed version written by `audit_long_bouts.py` |

## Analysis rules applied to the data
- 10 strike series: only the first 5 reviewed strikes of the instrumented arm (the 10 prescribed alternating strikes) are analyzed (`max_ipsi_strikes_10` in `pipeline_core.py`). Events were reviewed with the same criteria as the long bouts (`short_event_decisions.csv`: five exclusions and one phase substitution in four records without impact).
- 120 strike series: the main bout analysis uses the reviewed event list (`event_decisions.csv`); the automated list and capped lists are sensitivity analyses. The review was retrospective and based on the same EMG signals.
- The posterior deltoid of P5 in the 120 strike series contains artifacts and is excluded from all analyses of that series (`excluded_channels`); the raw signal is kept in `data/` unchanged.

## Reproduce
```
pip install -r requirements.txt
./run_all.sh        # macOS or Linux
run_all.bat         # Windows
```
Outputs go to `results/`. Python 3.10 or later. The large ensemble file `results/ensembles.npy` is regenerated by the scripts and is not stored in the repository.
